How data is handled

This policy describes PrintSheet's photo-processing app, optional usage statistics, and support pages. Privacy contact: shuitian13@gmail.com.

1. Photos, PDFs and local settings

Photos you select through the system photo picker or Files are processed on your device. Image normalization, previews, adjustments, layouts and PDF generation do not require a photo-upload service. PrintSheet does not send your photos, thumbnails, generated PDFs, filenames, file paths, template names or text you enter to its statistics service. Originals are not modified.

Unsaved working photos and generated PDFs are temporary local files. Save exports to a location you control. Named settings templates contain global settings only. Complete print projects are separate: when you save a project, its JPEG working copies, crops, per-photo quantities, paper and layout settings, name and optional manually entered measurement values and notes are stored in the app’s local Application Support directory. Projects survive app restarts until you delete them or remove the app, subject to system behavior and device backups. Removing a photo or clearing the current session does not delete an independently saved project. Delete the saved project in Print projects to remove that retained copy. No project contents, names, measurement values or notes are sent to the optional analytics service. The app still cleans stale temporary sessions; the operating system may also clear temporary files.

Cloud photo or file providers may download originals. When you choose a destination in the share sheet, that service processes the PDF under its own policies. Deleting PrintSheet removes its local app data subject to system behavior, but independently saved or shared exports remain in their destinations. Device backups depend on your system settings.

2. Your choice about usage statistics

Usage statistics are off by default. The first-run choice offers Allow or Not now. You can change the usage-statistics switch in Help at any time. The choice is stored on your device and remains in effect after restarting. Declining or switching it off does not disable photo layout or PDF export. Switching it off stops subsequent optional event uploads; it does not automatically remove events already received.

When you allow statistics, PrintSheet sends limited events to app-metrics.shuitian13.chatgpt.site to understand feature use, completion, processing time and fixed categories of failures, and to improve the app. The public collection interface accepts event submissions; viewing the statistics dashboard requires the owner's login.

3. What an allowed event contains

Events use a fixed allowlist: event type; source category; quantity and elapsed-time ranges rather than free text; sizing mode, layout and Fit / Fill options; fixed error codes; and applicable export-format or watermark-type categories. PrintSheet's applicable events describe PDF and photo-layout actions. The shared collection schema also serves other developer apps, but no cross-app identity is created.

An event also contains the app, app version and environment, a random event ID, and a random session UUID that lasts only for the current app process. A new process uses a new session UUID. PrintSheet does not save an installation ID, use an advertising ID, or link sessions across apps.

Photo contents, thumbnails, PDFs, entered text, image filenames, template names, email addresses, paths and raw exception messages are excluded from event payloads. No support message is automatically added to statistics.

4. Technical requests, service providers and access

The optional statistics service uses Sites and Cloudflare infrastructure. These support pages are hosted on GitHub Pages. GitHub states that it logs and stores visitors’ IP addresses for security, whether or not they are signed in; see GitHub Pages data collection and the GitHub Privacy Statement. Delivering and securing network requests necessarily involves technical request information such as an IP address and request headers. The app's event database does not store IP addresses or User-Agent values. This database rule is separate from infrastructure handling and does not mean the hosting providers never process technical request information.

These support pages add no analytics scripts, advertising cookies or browser-storage features. The language switch uses only the current page and its URL. Optional app event uploads are separate from visiting this website. For provider information, see Cloudflare's privacy policy and OpenAI's privacy policy.

5. Retention and deletion

Raw statistics events follow a 90-day retention rule and are removed by bounded periodic cleanup. Turning off statistics prevents future optional uploads; it does not retroactively delete earlier events. There is no persistent installation identifier for finding a person's events across app processes. You may contact us about a privacy or deletion request without sending photos or sensitive information; we will explain what can be located and what further information is necessary.

Apple's official sales and App Store reports are separate from this optional event service. Developer business records based on those reports may be retained longer for operations and accounting. Apple's reporting and device diagnostics follow Apple's own settings and policies; the app's statistics switch does not control those systems.

6. Support email

If you email shuitian13@gmail.com, the sender address and the information you choose to include are handled to investigate and reply to your request. Gmail and the involved email systems also process correspondence under their own policies. Do not send passwords, payment details or unnecessary private photos. Contact the same address to ask about support correspondence or request deletion. Support information is not included in app analytics.

7. Changes and contact

If data practices change, this policy and its update date will be revised. For questions or requests about this policy, email shuitian13@gmail.com.

数据如何处理

本政策说明 PrintSheet 照片排版 App、可选使用统计及支持网页的数据处理方式。隐私联系邮箱：shuitian13@gmail.com。

一、照片、PDF 与本地设置

用户通过系统照片选择器或“文件”主动选取的照片在本机处理。图片标准化、预览、单图调整、排版及 PDF 生成不需要上传照片。PrintSheet 不把照片、缩略图、生成的 PDF、文件名、路径、模板名称或用户输入的文字发送到统计服务，原文件不被改动。

未保存的工作照片和导出 PDF 是本地临时文件，请另存需要保留的 PDF。命名设置模板仅含全局参数；完整打印项目与模板不同：用户保存项目时，其 JPEG 工作副本、裁切、逐图份数、纸张和布局设置、项目名及可选手工测量值与备注，会保存在应用本机的应用支持目录。项目跨重启保留，直到用户删除项目或移除 App，实际行为也受系统及设备备份设置影响。移除当前照片或清空会话不会删除独立保存的项目；请在“打印项目”中删除项目以移除保留副本。项目内容、项目名、测量值和备注均不发送至可选统计服务。App 仍会清理过期临时会话，系统也可能清理临时文件。

云端照片或文件可能由系统及相应提供方下载。用户主动选择分享目的地后，该服务按自身规则处理 PDF。删除 App 会依系统行为移除本地应用数据，但已另存或分享的结果需在相应目的地删除；设备备份由系统设置控制。

二、使用统计由你选择

使用统计默认关闭。首次提示提供“允许”或“暂不”两项，可随时在“帮助”的使用统计开关中改变选择。选择保存在本机，重启后仍有效；拒绝或关闭不影响排版与 PDF 导出。关闭后停止后续可选事件上传，不会自动删除服务已接收的事件。

允许后，App 向 app-metrics.shuitian13.chatgpt.site 发送有限事件，用于了解功能使用、完成情况、处理耗时与固定类别错误，改进产品。公开采集接口只接收事件提交，查看统计看板需要所有者登录。

三、允许上传的事件字段

事件使用固定白名单：事件类型、来源类别、数量与耗时分桶、排版模式、布局、完整 / 铺满选项、固定错误码，以及适用的导出格式或水印类型类别。PrintSheet 实际事件描述 PDF 与照片排版操作；共享采集结构也服务开发者的其他 App，但不建立跨 App 身份关联。

事件还包含 App、版本、环境、随机事件 ID，以及仅在当前 App 进程使用的随机会话 UUID。新进程使用新的会话 UUID；不保存安装 ID，不使用广告 ID，不跨 App 关联会话。

事件载荷不包含照片内容、缩略图、PDF、用户文字、图片文件名、模板名称、邮箱、文件路径或异常原文，支持邮件也不会自动加入统计。

四、技术请求、服务方与访问

可选统计服务使用 Sites 和 Cloudflare 基础设施。这些支持网页由 GitHub Pages 托管。GitHub 说明，为了安全会记录并保存访问者的 IP 地址，无论是否登录；详见 GitHub Pages 数据收集说明及 GitHub 隐私声明。提供与保护网络请求涉及 IP 地址、请求头等技术请求信息。App 的事件数据库不保存 IP 或 User-Agent；这不等于托管基础设施从不处理这些技术信息，两者应分别理解。

这些支持网页不添加分析统计脚本、广告 Cookie 或浏览器存储功能；语言切换仅使用当前页面及其网址。访问网页与 App 可选事件上传是不同操作。服务方信息可参阅 Cloudflare 隐私政策和 OpenAI 隐私政策。

五、保留与删除

原始统计事件按 90 天保留规则，通过有界定期清理删除。关闭统计阻止未来可选上传，不会追溯删除早前事件。系统没有跨进程持久安装标识，因此不能按安装 ID 查找某个人的全部会话。如需咨询隐私或删除事项，可联系邮箱，我们会说明能否定位相关记录及所需的进一步信息；请勿发送照片或敏感资料。

Apple 官方销售及 App Store 报表与本可选事件服务独立，基于这些报表的经营与会计记录可能长期保存。Apple 报表和系统诊断由其自身设置与政策控制，App 的统计开关不控制这些系统。

六、支持邮件

用户向 shuitian13@gmail.com 主动发邮件后，发件地址与用户选择提供的内容用于调查和回复问题，Gmail 及相关邮件系统也按自身规则处理通信。请勿发送密码、付款资料或无关私人照片。可通过同一邮箱咨询支持邮件或提出删除请求；邮件内容不加入 App 统计。

七、更新与联系

数据处理方式改变时，我们会更新本政策和日期。有关本政策的问题或请求，请联系 shuitian13@gmail.com。
